# Sketch 001: Sidebar Clean

## Design Question
A sidebar fixa já é uma decisão herdada (scaffold 01-01). A questão aqui é a densidade/formato: ícone puro, ícone+label compacto, ou ícone+label espaçado (estilo da referência Filllo).

## How to View
open .planning/sketches/001-sidebar-clean/index.html

## Variants
- **A: Ícone só (rail, 72px)** — máxima densidade horizontal, tooltip no hover para o rótulo. Dá mais espaço pro conteúdo, mas exige memorizar os ícones.
- **B: Ícone + label compacta (192px)** — meio-termo: rótulos sempre visíveis, mas com padding enxuto (mais perto da densidade atual do app).
- **C: Ícone + label espaçada (232px, estilo Filllo)** — padding generoso, seção "Principal" com label de grupo, pill de fundo no item ativo mais largo.

## What to Look For
- Legibilidade dos 7 itens de navegação (Follow-ups, Leads, Importar, Pipeline, Templates, Sub-nichos, Lixeira) em cada densidade.
- Se o rail só-ícone (A) exige esforço demais pra reconhecer os itens no dia a dia.
- Se o espaçamento generoso de C combina com "clean/minimal" ou parece desperdício de espaço numa tela de trabalho.
