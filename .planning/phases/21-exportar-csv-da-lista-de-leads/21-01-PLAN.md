<decisions>
- **D-21-01**: A exportação é 100% client-side. O botão lê `table.getSortedRowModel().rows`
  (que é subconjunto de `getFilteredRowModel` — reflete os 3 filtros E a ordenação ativos),
  mapeia cada `row.original` (um `LeadRow`) para um objeto de colunas legíveis, gera o texto com
  `Papa.unparse` e dispara download via `Blob` + `URL.createObjectURL` + `<a download>` clicado
  programaticamente + `URL.revokeObjectURL`. Sem Server Action, sem rota de API.
- **D-21-02**: Motivo de perda sai como NOME. `LeadRow` ganha `motivoPerdaNome` computado no
  `data` useMemo de `lead-table.tsx` (mesmo padrão exato do `nichoNome` já existente) — um `Map`
  de `motivosPerda` (prop já recebida por `LeadTable`), `?? ""` quando `motivoPerdaId` é `null`.
  Escolhido em vez de threadar `motivosPerda` até a toolbar: menos superfície de mudança e o
  valor fica disponível em `row.original` para qualquer consumidor futuro.
- **D-21-03**: Estado vazio — o botão fica SEMPRE habilitado. Se `getSortedRowModel().rows` está
  vazio (filtros excluíram tudo), `buildLeadsCsv([])` gera um CSV só com a linha de cabeçalho.
  Não trava, não some, não desabilita.
- **D-21-04**: CSV injection é **mitigado** (não só aceito): `sanitizeCsvCell` prefixa com `'`
  (apóstrofo) qualquer célula cujo 1º caractere seja `=`, `+`, `-`, `@`, TAB ou CR. Justificativa:
  parte dos dados (nome, notas, interesse) vem de CSV de um parceiro (cowork) — não é 100% do
  próprio admin. Custo da mitigação é trivial. `Papa.unparse` já faz o quoting de aspas/`;`/quebra
  de linha sozinho (não precisa reimplementar).
- **D-21-05**: Encoding pt-BR — o texto do CSV é prefixado com **BOM UTF-8** (`"\uFEFF"`) e usa
  **`;` como delimitador** (`Papa.unparse(..., { delimiter: ";" })`). É o que o Excel em locale
  pt-BR espera (lá `,` é separador decimal). Mesmo idioma dos dois lados do `src/lib/csv-encoding.ts`
  do import — aqui só o lado de escrita.
- **D-21-06**: Colunas exportadas, nesta ordem: Nome, Telefone, Canal, Nicho, Etapa, Follow-up,
  Origem, Tipo de origem, Interesse, Valor estimado, Motivo de perda, Tentativas de contato,
  Notas, Criado em. NÃO exportar `id`, `nichoId`, `motivoPerdaId`, `deletedAt`, `importBatchId`,
  `sequenciaPosicao`, `stageChangedAt`, `updatedAt` (ruído / ids crus).
- **D-21-07**: Nome do arquivo `leads-AAAA-MM-DD.csv` (`format(new Date(), "yyyy-MM-dd")` de
  `date-fns`, já no projeto).
- **D-21-08**: Verificação por **code+data** (host 4GB não roda `dev` + navegador + sessão —
  precedente Fases 18/19/20). O download real e o "abre no Excel" ficam como UAT humano
  NÃO-BLOQUEANTE. Ship por push direto na `main` (sem PR), consistente com Fases 16-20.
</decisions>
