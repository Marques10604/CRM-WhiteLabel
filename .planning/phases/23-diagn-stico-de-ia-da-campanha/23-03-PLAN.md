## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → repositório | Dependências novas entram no repo e rodam no processo do servidor. |

| processo servidor → bundle do cliente | A `ANTHROPIC_API_KEY` não pode atravessar esta fronteira. |
