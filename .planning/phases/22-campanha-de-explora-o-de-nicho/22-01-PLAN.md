## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser (admin) → Server Actions | `campanha-actions.ts` recebe `FormData` bruto de um form client-side — entrada não confiável (o mesmo admin, mas o mesmo raciocínio de defesa em profundidade de todas as outras Server Actions do projeto) |
| Server Actions → SQLite (`data/crm.db`) | Toda escrita passa pelo query-builder parametrizado do Drizzle — nunca concatenação de string SQL |
| Script de migração → `data/crm.db` | Processo Node standalone rodando fora do runtime do Next, escreve DDL diretamente via `better-sqlite3` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
