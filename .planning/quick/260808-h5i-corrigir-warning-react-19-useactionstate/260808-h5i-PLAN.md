<objective>
Corrigir o warning do React 19 emitido no console do navegador (dev mode) ao submeter o
formulário de lead:

> "An async function with useActionState was called outside of a transition. This is likely
> not what you intended (for example, isPending will not update correctly). Either call the
> returned function inside startTransition, or pass it to an `action` or `formAction` prop."

Origem exata: `src/components/lead-form-dialog.tsx (177:5)` @ `onSubmit`, na linha
`formAction(new FormData(formRef.current));`.

Purpose: além de limpar o console, o warning aponta um bug real de UX — `pending`
(3º valor de `useActionState`) não atualiza de forma confiável quando `formAction` é
chamado fora de uma transition, ou seja, o botão "Salvando..." e o `disabled={pending}`
dos botões Cancelar/Salvar hoje não são garantidos durante o submit.

Output: `src/components/lead-form-dialog.tsx` com `startTransition` importado de `"react"`
e a chamada de `formAction` envolvida em `startTransition(() => { ... })`.
</objective>
