# Quick 260910-p6x: Correções seguras da revisão ui-ux-pro-max

## Objetivo

Aplicar os **6 itens isolados** de acessibilidade e polimento apontados pela
revisão ui-ux-pro-max. Todos são aditivos ou puramente de `className` — **zero
mudança em lógica de interação, handler, query ou estado testado**.

Agrupados em 3 tarefas:

| Tarefa | Itens | Escopo |
|--------|-------|--------|
| 1 | 1 + 2 | Acessibilidade global (reduced-motion + skip-link) |
| 2 | 3 + 4 | Polimento de dados e forms (tabular-nums + `mode: "onBlur"`) |
| 3 | 5 + 6 | Wizard de import CSV (stepper + skeleton) |

Ordem **sequencial obrigatória**: a Tarefa 3 depende da Tarefa 1 (o
`@media (prefers-reduced-motion)` global é o que neutraliza o `animate-pulse`
do skeleton — o componente não ganha guarda própria).

## Fora de escopo (NÃO tocar)

- `src/components/pipeline-board.tsx` — código de drag-and-drop testado
- `src/components/followup-dashboard.tsx`
- Varredura/normalização de `text-[..px]` no app — fica no backlog
- Qualquer primitivo novo do registry shadcn (`npx shadcn add ...`)
- Qualquer dependência nova de npm (zero instalação nesta tarefa)

## Regras de marca (valem nas 3 tarefas)

- **Só tokens de cor** (`bg-primary`, `text-muted-foreground`, `bg-muted`,
  `border`, `bg-background`, `text-foreground`, `ring-ring`). **Zero hex, zero
  escala nomeada do Tailwind** (`bg-amber-50`, `text-white`, `bg-zinc-*`) — é
  exatamente o que `npm run verify:brand` reprova.
- Espaçamento na **grade de 4px** (`gap-2`, `gap-3`, `gap-6`, `px-4`, `py-2`,
  `h-6 w-6`, `h-10`, `h-12`).
- **Sem emoji** em qualquer string de UI.
- `cn()` do projeto usa `tailwind-merge` — passar `text-right` para um
  `<TableHead>` sobrescreve o `text-left` do primitivo corretamente.

## Modelo de ameaças

Não aplicável a esta tarefa: nenhuma fronteira de confiança nova é cruzada.
As mudanças são CSS/`className`, um `<a>` interno (`href="#conteudo"`, âncora
local, sem URL externa), uma opção de validação client-side do react-hook-form
(`mode: "onBlur"` — não substitui nem afrouxa o `zodResolver` nem a validação
do servidor) e um sub-componente de apresentação sem input. **Zero pacote novo
instalado** → o portão de legitimidade de pacote não se aplica.

## Task 1 — Acessibilidade global: reduced-motion + skip-link

- **files:** `src/app/globals.css`, `src/app/layout.tsx`
- **action:**
  - **`src/app/globals.css`** (item 1) — acrescentar, **no FIM do arquivo,
    depois do bloco `@layer base { ... }`**, um bloco de mídia solto (fora de
    qualquer `@layer`, fora de `:root` e de `.dark`):
    - seletor `*, *::before, *::after` dentro de
      `@media (prefers-reduced-motion: reduce)`;
    - declarações, todas com `!important`: `animation-duration: 0.01ms`,
      `animation-iteration-count: 1`, `transition-duration: 0.01ms`,
      `scroll-behavior: auto`.
    - **Motivo do posicionamento:** `scripts/check-contrast.cjs` extrai os
      corpos de `:root` e `.dark` por varredura de chaves balanceada — inserir
      o bloco DENTRO de um deles quebraria o parser. Fora de `@layer` porque
      utilitários do Tailwind v4 vivem em layer própria e precisam perder para
      este bloco.
    - Não alterar nenhuma variável de token existente. Nenhum componente é
      tocado neste item.
  - **`src/app/layout.tsx`** (item 2) — skip-link:
    - Inserir um `<a href="#conteudo">` com o texto `Pular para o conteúdo`
      como **PRIMEIRO filho do `<body>`**, antes de `<ThemeProvider>`.
    - Classe: `sr-only` por padrão, visível no foco via `focus:not-sr-only`.
      Como o `<body>` é `flex`, o estado visível PRECISA sair do fluxo:
      `focus:absolute focus:left-4 focus:top-4 focus:z-50`. Aparência:
      `focus:rounded-md focus:border focus:bg-background focus:px-4
      focus:py-2 focus:text-sm focus:font-medium focus:text-foreground
      focus:ring-2 focus:ring-ring`. **Não** usar `focus:outline-none`
      (o `outline-ring/50` do `@layer base` é o foco padrão do projeto).
    - No `<main>` já existente: adicionar `id="conteudo"` e `tabIndex={-1}`,
      preservando `className="min-w-0 flex-1 px-8 py-8"` intacto.
    - **`src/components/app-sidebar.tsx` NÃO muda** — já foi conferido: a
      sidebar não usa `tabIndex` positivo nem gerencia foco, e o skip-link
      vem antes dela na ordem do DOM, então já é o primeiro tabbable da
      página. Deixar o arquivo intocado (confirmação, não mudança).
- **verify:**

  - `npm run lint` — exit 0
  - `npm run verify:brand` — exit 0
  - `npm run check:contrast` — exit 0 (prova que o parser de `:root`/`.dark`
    continua íntegro depois da edição do CSS)
  - `npm run verify:theme` — exit 0
  - Portão do item 1 (ignora comentários CSS):
